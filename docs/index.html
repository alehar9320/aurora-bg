Quick Start

Choose your preferred integration method.

<script src="https://cdn.jsdelivr.net/npm/aurora-bg/dist/aurora.umd.js"></script>
<script>auroraBg.defineAuroraBg()</script>
<aurora-bg colors="#00ff88,#00aaff" density="0.7"></aurora-bg>

Add the script tag, define the element, and drop <aurora-bg> anywhere in your HTML.

$ npm install aurora-bg
import { defineAuroraBg } from 'aurora-bg'
defineAuroraBg()

Then use <aurora-bg> in any framework — React, Vue, Svelte, Angular, or vanilla HTML.

import { AuroraEngine } from 'aurora-bg'

const canvas = document.getElementById('my-canvas')
const engine = new AuroraEngine(canvas, {
  colors: ['#00ff88', '#00aaff'],
  density: 0.7,
  speed: 1.0,
})
engine.start()

For full control — manage the canvas element and engine lifecycle yourself.

Features

Why Aurora BG stands out.

  • Zero runtime dependencies
  • Canvas-based, hardware accelerated (60fps)
  • Web Component — use as <aurora-bg>
  • Programmatic API for full control
  • Auto-resizes with ResizeObserver
  • Respects prefers-reduced-motion
  • Scroll-based parallax support
  • Mountain silhouette layering
  • Twinkling star field
  • Ion micro-particle drift
